# Small Area Mental Health Index (SAMHI)

The Small Area Mental Health Index (SAMHI) is a composite index of mental health need for each Lower Layer Super Output Area (LSOA) in England, developed by the Place-Based Longitudinal Data Resource (PLDR). It combines data on NHS mental health prescriptions, inpatient admissions, and incapacity/disability benefits into a single standardized annual measure (2011–2022).
